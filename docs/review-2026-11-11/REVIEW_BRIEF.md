1. 위원 링크를 매번 다시 발급하지 않는다. 잃어버려도 재발급하지 않고 같은 링크를 계속 쓴다. 예전 링크를 죽이지 않는다.
   - 서버가 링크 원문(inviteToken)을 저장하고 관리자 화면에만 `invitePath`로 내보낸다. 7일 만료 없음.

3. 동의를 못 받은 사람은 「익명화」 버튼으로 이름 가운데 글자를 0으로 바꾼다(권준구 → 권0구). 사람별 버튼과 전원 버튼. 되돌릴 수 없음.
4. 매뉴얼(`tools/recruitment-manual/build_manual.py` → `public/recruitment/manual/*.html`)과 `privacy.html` 문구를 새 동작에 맞춘다.
