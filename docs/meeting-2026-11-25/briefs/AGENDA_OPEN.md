# 누구나 안건 설정하기 + 대기 화면 「오늘의 안건」

사용자 결정(2026-11-25):
1. **회의 만들기**: 로그인한 교직원 누구나(이미 반영: `routes.js` POST /meetings 는 login, 수정·삭제·잠금 풀기는 만든 사람 또는 관리자 `canManage`. `list.js` 단추 「회의 만들기」 누구에게나).
2. **안건 설정하기**: 회의에 들어온 **누구나**(주관자만이 아니라 참석자 pt 도) 안건을 추가할 수 있다. 안건은 **제목만으로도** 만들 수 있고, 관련 자료(PDF·HWP·HWPX·PPTX)를 **미리 올려 둘 수도** 있다(회의 시작 전 `ready` 상태에서도, 진행 중에도).
3. **대기 화면**: 회의가 시작되기 전(그리고 진행자가 아직 아무 쪽도 띄우지 않았을 때) 무대에 **「오늘의 안건」** 목록이 크게 떠 있다. 순서 번호, 제목, 올린 사람 이름, 자료가 있으면 쪽 수 표시. 「안건 추가」 단추와 각 안건에 「자료 올리기」.

## 권한
- 추가·자료 올리기: 회의 참석자 누구나(pt 있는 사람). 끝난 회의(ended·deleting)에서는 안 됨.
- 자기 안건의 제목 고치기·지우기·자료 바꾸기: 올린 사람(cid 또는 같은 기기 person) 또는 주관자.
- 순서 바꾸기: 주관자만.
- 상한: 회의당 안건 30개, 한 사람 10개, 기존 업로드 크기·쪽 수 한도(50MiB, 200쪽)와 업로드 속도 한도 그대로. 이름·제목 길이 제한, XSS 안전(textContent).

## 고칠 것
- 서버 `lib/zzoom/routes.js`: 제목만 있는 안건 만들기(새 라우트 또는 기존 agenda 라우트 확장, 자료는 나중에 붙이기), 업로드 init/commit 을 참석자에게 열고 `uploadedBy{cid,name}` 기록, 위 권한. 안건 문서 모양은 `CONTRACTS.md` 를 고쳐 적는다.
- 규칙 `storage.rules`·`firestore.rules` 쭘 블록: 참석자 토큰(role viewer)도 **자기 uploadId 경로에만** 원본·쪽 그림 쓰기. Rules 시험 API(게시 아님)로 허용/거절 표.
- 화면: 새 모듈 `public/zzoom/agenda.js`(+`agenda.css`, 접두사 `.za-`) — 대기 화면 「오늘의 안건」, 안건 추가 창, 자료 올리기(기존 `upload.js` 의 변환·업로드 흐름을 함수로 꺼내 재사용, 직접 fetch 금지 — `api.js` 함수로). `app.js` 에 모듈 붙이기, 무대가 비어 있거나 status=ready 일 때 대기 화면을 보이게. 주관자 막대의 안건 관리 창(`host.js`)은 순서 바꾸기 위주로 두고 추가 기능은 agenda.js 를 부른다.
- `api.js`·`app.js` 는 다른 에이전트(뼈대 담당)가 감사 지적 U02·U14 를 고치는 중이다. **새 함수·새 줄을 덧붙이는 것만** 하고 기존 줄은 바꾸지 않는다. `record.js` 는 다른 에이전트 몫이라 건드리지 않는다.

## 추가 결정(2026-11-25, 사용자)
4. **터치하면 이동**: 대기 화면 「오늘의 안건」에서 안건을 누르면 그 안건(자료 첫 쪽)으로 이동한다. 진행자가 아닌 사람이 누르면 자기 화면만 자유 보기로 이동한다.
5. **화면은 무조건 발표자가 가져간다**: 각 안건에 「발표하기」 단추. 누르면 그 사람이 **발표자(진행자)** 가 되고, 모든 참석자 화면이 발표자 화면을 따라간다(자유 보기 중이던 사람도 끌려옴, forceSeq). 발표자는 쪽 넘기기·확대가 모두에게 반영된다.
   - 누가 누를 수 있나: 참석자 누구나(주관 코드 없이). 다른 사람이 발표 중이면 「지금 ○○ 선생님이 발표 중이에요. 이어서 발표할까요?」 확인 뒤 넘겨받는다. 주관자는 언제든 다시 가져올 수 있다.
   - 서버: 기존 진행 넘겨받기(presenter·live·rev·epoch)를 참석자에게 열되, 넘겨받기 속도 한도(사람당 10초 1회)와 끝난 회의 금지. 레드팀 관점(남의 발표 가로채기 폭주)을 시험으로.
   - 주관자 전용으로 남는 것: 회의 시작·끝내기, 판서 잠금, 순서 바꾸기, 쪽 지우기, 녹음.
   - **확인 창(사용자 지정 문구)**: 「발표하기」를 누르면 먼저 확인 창을 띄운다. 본문 문구는 정확히 **「지금부터 화면이 전송됩니다」**, 단추는 **「예」·「아니오」**. 「예」를 눌러야 발표자가 되고, 「아니오」면 아무 일도 없다. 다른 사람이 발표 중이면 같은 창에 「지금 ○○ 선생님이 발표 중이에요.」 한 줄을 위에 더한다(창은 하나만).
   - **익명(사용자 정정)**: 이 앱은 익명 커뮤니티다. 안건·발표에 **사람 이름을 보이지 않는다.** 대기 화면에 「올린 사람」 표시를 빼고, 발표 중 안내는 「지금 다른 분이 발표 중이에요.」로(이름 없음). 서버 응답·Firestore 안건 문서에도 올린 사람 이름을 싣지 않고, 권한 판정용 cid·person 해시만 둔다(화면에는 「내 안건」 표시만).
