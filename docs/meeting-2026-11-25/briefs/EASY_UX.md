# 쭘을 처음 보는 선생님도 바로 쓰게 (사용자 요구 2026-11-26)

사용자 말: "이 앱은 직관적이고 쉬워야 해. 교사들이 메인 타깃이라 처음 보는 사람도 쓸 수 있게끔 정말 쉽게 만들어."

## 대상
- 컴퓨터를 잘 모르는 50대 선생님도 포함. 설명서 없이, 누구에게 묻지 않고 첫 회의에 들어와 따라갈 수 있어야 한다.
- 기기: 교실 PC(엣지 1280), 태블릿(820), 휴대폰(390).

## 원칙
1. **한 화면에 할 일 하나가 가장 크게.** 지금 무엇을 하면 되는지 한눈에. 주 행동 단추는 하나만 강조.
2. **쉬운 말.** 「진행·주관·뷰어·동기화·세션」 같은 낱말 대신 「발표」「내 화면」「모두의 화면」처럼. 단추 글자는 동사로(「회의 들어가기」「자료 올리기」「발표하기」). 아이콘만 있는 단추 금지(글자 함께).
3. **지금 상태를 늘 알려 준다.** 「지금 ○번 안건을 보고 있어요」「모두의 화면을 따라가는 중」「내 화면으로 보는 중 · 발표 화면으로 돌아가기」.
4. **처음 한 번만 짧은 안내.** 첫 입장 때 3장 이하 말풍선 안내(다시 보지 않기). 빈 화면에는 다음 행동을 알려 주는 문장 + 단추.
5. **실수해도 괜찮게.** 지우기는 되돌리기나 확인. 화면을 망가뜨리는 동작(남의 화면 바꾸기)은 확인(발표하기 확인 창 문구는 사용자 지정 그대로).
6. **큰 글자·큰 단추.** 본문 16px 이상, 단추 높이 44px 이상(휴대폰 48), 대비 WCAG AA.
7. **기능 숨기기.** 자주 안 쓰는 것(판서 잠금, 순서 바꾸기, 녹음 설정 등)은 「더 보기」 안으로. 참석자에게는 참석자에게 필요한 것만.
8. 문체: 짧은 존댓말, 가운뎃점·화살표 나열 없음, 실제 사람 이름 없음. 익명 원칙 유지.

## 바꾸면 안 되는 것
- 발표하기 확인 창: 본문 「지금부터 화면이 전송됩니다」, 단추 「예」「아니오」, 바쁠 때 「지금 다른 분이 발표 중이에요.」.
- 전체 익명, 누구나 회의 만들기·안건 추가, 화면은 발표자가 가져감.
- 서버 API·계약(CONTRACTS.md) — 화면만 바꾼다.
