# 쉬운 화면 개편 — 구현 (3팀 병렬)

먼저 읽기: `briefs/EASY_UX.md`(원칙), `reports/EASY_UX_REVIEW.md`(장면별 표·낱말 바꾸기 표·첫 입장 안내 문구), `CONTRACTS.md`.

## 사용자 결정 (2026-11-26)
- 「주관자」 → **「회의 담당자」**(짧게 「담당자」), 「주관 코드」 → **「담당자 비밀번호」**. 「진행/진행자」는 모두 **「발표/발표자」**로 통일.
- **「발표 마치기」 단추**: 발표자 본인과 담당자에게. 서버 `POST /api/zzoom/:mid/presenter/end`(CONTRACTS.md 참고) — 누르면 모두 「오늘의 안건」 대기 화면.
- 회의를 만든 사람은 같은 로그인이면 코드 없이 바로 담당자(서버가 이미 처리, 화면은 「담당자 비밀번호 넣기」를 앞에 내세우지 말 것).
- 백암이 탭 이름 「회의진행 앱」은 그대로.
- 바꾸면 안 되는 것: 발표하기 확인 창(본문 「지금부터 화면이 전송됩니다」, 「예」「아니오」, 바쁠 때 「지금 다른 분이 발표 중이에요.」, 첫 초점 「아니오」), 전체 익명, 서버 API.

## 팀과 파일(겹치지 않게 — 남의 파일은 고치지 말고 그 팀 보고서 「요청」에 적기)
- **A 입구·뼈대**: `index.html`, `app.js`(머리줄·상단 막대), `list.js`·`list.css`, `join.js`, `zzoom.css`(글자·단추 크기 토큰: 본문 16px↑, 단추 44px↑·휴대폰 48px, 대비 AA), 새 `onboard.js`(첫 입장 안내 3장, 담당자용 별도, 「다시 보지 않기」 localStorage `zz_onboarded_v1`). 장면 B1~B4, B13.
- **B 무대·안건·발표**: `viewer.js`, `agenda.js`·`agenda.css`, `draw.js`·`draw.css`(도구 막대가 상태 띠를 가리지 않게), `board.js`, `api.js`(새 함수 **덧붙이기만**: presenterEnd). 장면 B5~B9, 큰 「지금 상태」 띠(「모두의 화면을 따라가는 중」「내 화면으로 보는 중 · 발표 화면으로 돌아가기」「내가 발표 중 · 발표 마치기」), 「발표 마치기」.
- **C 옆칸·담당자**: `chat.js`, `hands.js`, `poll.js`, `host.js`·`host.css`, `record.js`, 해당 css. 장면 B10~B12. 담당자 막대는 주 단추 하나만 강조, 드문 기능은 「더 보기」.

## 공통
- 낱말 바꾸기 표를 자기 파일 안에서 전부 적용. 아이콘만 있는 단추 금지(휴대폰 포함 글자 함께).
- 기존 e2e(`tests/zzoom/*_e2e.py`, 하네스)의 문구 단언은 새 낱말로 고치고, 자기 장면 시험을 추가. 엣지(channel='msedge')·크로미움, 1280·820·390. 스크린샷은 저장소 밖에 저장해 직접 보기.
- `npm run test:zzoom` 통과 유지. 커밋·푸시·배포 금지. 띄운 서버는 끝에 끄기. 오래 걸리는 명령은 timeout.
- 보고 `reports/EASY_UX_<팀>.md`, 진행 상황 수시 저장. 마지막 답변 8줄 이내.
