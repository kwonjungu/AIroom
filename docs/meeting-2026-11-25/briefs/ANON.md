# 쭘 전체 익명화

사용자 결정(2026-11-25): 쭘은 **익명 커뮤니티**다. 어디에도 사람 이름을 보이거나 저장하지 않는다.

## 바꿀 것
- **입장**: 이름을 묻지 않는다. 「입장하기」 한 번으로 들어간다. 서버 `/:mid/join` 은 name 을 받지 않고(와도 버림) 저장하지 않는다. 사람 구분은 cid·person 해시(기기·세션)만. 같은 기기 재입장 = 같은 사람(투표 1표, 채팅 한도 유지).
- **채팅**: 이름 없이 말풍선만. 내 글만 「나」 표시, 남의 글은 표시 없음. 지우기는 본인·주관자 그대로.
- **손들기**: 이름 대신 손 든 사람 수와 순서 번호만(주관자에게도 이름 없음). 주관자는 「모두 내리기」·「하나 내리기(가장 먼저 든 손)」.
- **접속자**: 이름 목록 없이 수만(연결 중·연결 확인 중 수).
- **투표**: 공개 투표(이름 공개) 기능을 없애고 모두 비공개. 결과는 항목별 수만.
- **발표 중 안내·안건**: 이름 없이(다른 에이전트가 `AGENDA_OPEN.md` 로 하는 중).
- **AI용 기록(md 내보내기)**: 이름 칸 없이. 받아쓰기 녹취에도 화자 이름 없음.
- **Firestore·Redis 문서**에서 name 필드 제거(people·chat·hands·strokes·polls). 규칙 쭘 블록도 name 검사를 빼고 맞춘다. 판서 선의 name 도 제거.
- **`localStorage.airoom_ws_name`** 을 쭘에서 읽지도 쓰지도 않는다(codocs 명부 가져오기 제거).
- 문구 예: 「입장하기」, 「익명으로 참여해요. 이름은 저장되지 않아요.」

## 나누기(겹치지 않게)
다른 에이전트가 같은 때 `routes.js` 의 **안건·업로드·발표자(presenter/live 넘겨받기)** 부분과 새 `agenda.js`, `api.js`·`app.js` 덧붙이기를 고친다. 너는 `routes.js` 의 **join·people·heartbeat·chat·hands·polls·export(md)·whisper** 부분만 고치고, 같은 파일이라 Edit 는 작은 단위로 한다. 화면은 `join.js`·`list.js`(이름 관련만)·`chat.js`·`hands.js`·`poll.js`·`host.js`(접속자·손 목록 부분)·`draw.js`(선 name 제거만). `api.js` 는 기존 함수의 name 인자만 빼고 새 함수는 덧붙이기만.
`record.js` 는 다른 에이전트 몫(손대지 말 것).
