# 화면 감사 R2 고침 (FIX_UI_R2)

기준: `AUDIT_UI_R2.md`. 범위는 `public/zzoom/*` 와 `tests/zzoom` 화면 시험이다. 서버(`lib/zzoom/*`)와 규칙은 건드리지 않았다. 커밋, 푸시, 배포는 하지 않았다.

## 1. 고친 것
| 번호 | 파일 | 고친 내용 |
|---|---|---|
| U16 「화면은 무조건 발표자가 가져간다」 | app.js, agenda.js, zzoom.css | 회의 구독에서 다른 분이 새로 발표하거나(forceSeq 증가) 발표자가 바뀌면(내가 발표자가 아닐 때) `yieldToPresenter()` 를 부른다. 손으로 연 「오늘의 안건」 패널을 닫고(`cmd:yield`), 열린 창은 닫고, 1024px 미만에서는 옆칸 서랍과 안건 덮개도 닫는다. 입력 중인 창(제목을 적었거나 파일을 고른 「안건 추가」, 바꾼 이름이 있는 「이름 바꾸기」, 올리는 중인 「자료 올리기」와 주관자 「안건 올리기」)은 닫지 않고 머리줄 아래 「○○ 이어서 하기」 단추로 접는다. 접힌 창은 무대를 막지 않고, 누르면 입력값 그대로 다시 열린다. 접을 때 알림 한 줄(「다른 분이 발표를 시작했어요. 쓰던 창은 접어 두었어요.」)을 띄운다 |
| U17 화면 이동 뒤 남는 창 | app.js, agenda.js | `go()` 가 떠날 때 열린 창을 모두 닫는다. agenda 는 떼어질 때 자기가 연 창을 닫는다 |
| U18 발표 확인 창 첫 초점 | app.js, agenda.js | 창 단추에 `focus: true` 를 주면 그 단추에 첫 초점을 준다. 발표 확인 창은 「아니오」. 문구(「지금부터 화면이 전송됩니다」, 「예」「아니오」, 「지금 다른 분이 발표 중이에요.」)와 단추 순서는 그대로다 |
| U14 390 손들기 | hands.js, side.css | 「손」 칸 머리 아래에 손들기 단추(`.zs-hands-raise`, 폭 전체, 44px)를 더했다. 쪽 막대 단추와 상태(눌림, 글자)가 같이 바뀐다 |
| U04 손들기 타이머 | hands.js | 1.5초 타이머를 하나만 기억하고 새로 누르면 지운다. unmount 때 지우고, 떼어진 뒤에는 그리지 않는다 |
| U19 익명(원본 파일 이름) | agenda.js, upload.js, api.js, viewer.js, host.js | 화면에 원본 파일 이름을 보이지 않는다(「자료 1개를 골랐어요 (그림)」처럼 종류만). 안건 제목을 파일 이름으로 미리 채우지 않는다. 서버에 보내는 `originalName` 은 `원본.확장자` 로 바꿨고, 「원본 받기」 파일 이름은 안건 제목과 확장자로 만든다(`api.originalFileName`) |
| U15 로그인 순서 | api.js | 실시간 로그인과 로그아웃을 한 줄(`authOp`)로 세웠다. 늦게 끝난 옛 입장은 자기 뒤에 다른 로그인이 줄에 들어왔으면 로그아웃하지 않는다. 세대 번호(`gen`)와 함께 동작한다 |
| U12 경로의 계정 폴더 이름 | assets/_src/manifest.json, convert.py, 문서 5개 | manifest 의 `source` 를 `~/.codex/...` 로 바꾸고 convert.py 가 `expanduser` 로 읽는다. D5.md, FIX_ENGINE.md, publish/README.md 의 경로를 지웠고, PII_SWEEP.md, PRECOMMIT_SCAN.md 의 이름은 가운데 글자를 가렸다. `tests/zzoom/__pycache__` 를 지웠다 |

### d5 실패 30건의 원인
d5 「안건 관리」 시험이 원본 받기 파일 이름을 옛 동작(원본 이름 `교육과정.pdf`)으로 기대한다(d5_e2e.py:210). U19 로 받기 이름을 안건 제목과 확장자(`2027 교육과정 운영 계획.pdf`)로 바꿨으므로 이 단언이 실패하고, 그 시험이 「안건 관리」 창을 연 채 끝나 뒤 시험(올리기, 취소, 오류, 녹음, 회의 끝내기)이 창 두 개 때문에 줄줄이 실패한다. 다섯 크기 모두 같은 여섯 항목이다. 조정자 지시로 이 시점부터 코드를 고치지 않았으므로 d5_e2e.py:210 의 기대값을 `2027 교육과정 운영 계획.pdf` 로 바꾸는 일이 남았다. 이 결정(원본 이름 대신 제목으로 받기)을 바꾸려면 api.js `originalFileName` 을 되돌리면 된다.

참고: d5 를 돌린 08:30 무렵 public/zzoom 의 agenda.js, api.js, host.js, upload.js, viewer.js 등이 다른 팀(쉬운 화면 개편 3팀)에 의해 바뀌고 있었다. 위 다른 e2e 숫자는 그 전후에 돈 것이라 3팀 변경 뒤에는 다시 돌려야 한다.

## 3. 남은 것
- d5_e2e.py:210 기대값 바꾸기(위).
- 접힌 창 단추는 1280, 820 에서 머리줄 아래 가운데, 768px 미만에서는 오른쪽 위에 놓인다. 토스트(z 70)가 3.5초 동안 손들기 단추를 덮는 것은 R2 때와 같다(ui_r2 시험은 토스트를 지우고 잰다).
- 접힌 「안건 관리」(주관자)는 이름 칸에 초점이 있을 때만 접고, 접을 때 칸을 벗어나며 저장된다. e2e 로는 확인하지 않았다(코드 읽기).
- 실제 Firebase 로그인 순서는 가짜 모듈로만 확인했다.
