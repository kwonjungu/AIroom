# 쭘 변환기 실측 (CONVERT_PERF)

시험일 2026-11-25. 로컬 `PORT=3871 node server.js` 의 `/zzoom/convert/index.js` 를 Python Playwright 로 불러 실제 `convert()` 를 메인 스레드에서 실행했다. 엣지(`channel='msedge'`, 헤드리스)와 Playwright 크로미움. CPU 4배 느리게는 CDP `Emulation.setCPUThrottlingRate=4`(엣지만). 코드는 고치지 않았다. 표본은 모두 scratch 에서 만든 가짜 문서다(실제 학교 문서 없음).

표본: `p30.pdf`(30쪽), `p200.pdf`, `p201.pdf`(글 40줄 반복 + JPEG 900x600 한 장 + 도형, 쪽당 약 35KB), `deck30.pptx`(pptxgenjs 30장: 제목·글머리·도형·표), `permit.hwpx`·`permitcal.hwpx`(저장소 `templates/` 양식, 각 1쪽). 실제 HWP(바이너리) 표본은 저장소에 없고 학교 문서는 쓰지 않아 이번에 재지 못했다.

## 1. 형식별 시간(쪽당)

| 형식 | 표본 | 엣지 1배 | 엣지 CPU 4배 | 크로미움 1배 |
|---|---|---|---|---|
| PDF | 30쪽 | 7.5초 (0.25초/쪽) | 14.8초 (0.49초/쪽) | 6.7초 (0.22초/쪽) |
| PDF | 200쪽 | 53.7초 (0.27초/쪽) | 59.2초 (0.30초/쪽) | 52.8초 (0.26초/쪽) |
| PPTX | 30장 | 6.8·6.6초 (0.22초/장) | 13.7·10.0초 (0.4초/장) | 5.8·6.1초 (0.2초/장) |
| HWPX | 1쪽 양식 | 첫 실행 1.8초(WASM 받기 포함), 이후 0.3초 | 첫 실행 6.9초, 이후 0.6~0.8초 | 첫 실행 1.7초, 이후 0.3초 |
| HWP | 없음 | 못 잼 | 못 잼 | 못 잼 |

- HWPX 는 1쪽짜리뿐이라 쪽당 값은 신뢰하기 어렵다. 이전 convert-check.md 에는 22쪽 4.8~9.3초(쪽당 약 0.3초)가 있다.
- 200쪽 PDF 가 4배 느리게에서도 59초에 그친 것은 쪽당 시간이 CPU 보다 래스터·WebP 인코딩(비CPU 쪽)에 묶인 것으로 보이며, 갤럭시탭 실기에서는 다를 수 있다. 첫 실행 값은 변환기·WASM 받기 시간을 포함한다.

## 2. 200쪽 PDF 전체

| 항목 | 엣지 1배 | 엣지 4배 | 크로미움 |
|---|---|---|---|
| 전체 시간 | 53.7초 | 59.2초 | 52.8초 |
| 6분(360초) 제한 | 안 (15%) | 안 (16%) | 안 (15%) |
| 결과 WebP 쪽 그림 합 | 5.2MB (쪽당 26KB) | 5.2MB | 5.2MB |
| 썸네일 합 | 0.8MB | 0.8MB | 0.8MB |
| JS 힙(`performance.memory`, 100ms 표집 최고) | 119MB (시작 113MB, 끝 43MB) | 76MB (끝 43MB) | 25MB 로 고정 표시 |

- 크로미움의 힙 값은 `performance.memory` 가 거칠게 양자화돼 25MB 로 안 변해 쓸 수 없다. 엣지 값도 다른 시험 직전의 잔여가 시작값에 섞여 거칠다. 변환이 끝나면 힙은 43MB 로 내려가 쪽 그림이 쌓여도 힙에는 Blob 크기만 잡히지 않는 것으로 보인다(Blob 은 JS 힙 밖). 실제 프로세스 메모리(GPU·Blob 포함)는 못 쟀다.
- 쪽 그림이 가짜 JPEG 한 장 위주라 실제 사진 많은 문서는 쪽당 WebP 가 더 클 수 있다(이전 65쪽 PDF 3.4MB, 80장 PPTX 3.8MB 값 참고).

## 5. 결론과 남은 것

- 200쪽 PDF 는 이 PC 에서 약 1분, 6분 제한의 6분의 1 이하. 4배 느린 CPU 에서도 1분 안팎이라 갤럭시탭급도 제한 안으로 보이나, 실기 확인은 아니다.
- 재지 못한 것: 실제 HWP 표본, 사진 많은 200쪽, 200쪽 PPTX·HWPX, 프로세스 전체 메모리(작업 관리자 기준), 파이어폭스·사파리, 갤럭시탭 실기.
- 코드 수정·커밋 없음. 시험 서버(3871)는 종료했다.
