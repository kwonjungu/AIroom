## 1. 확인한 것

### ① 고친 코드 읽기(core.js:228-255, pptx.js:75-82)
- 안전망이 try 안에 있다. `src = canvas` 를 먼저 적고 새 캔버스를 만들기 때문에, 어느 줄에서 실패해도 finally 가 원래 캔버스(src)와 새 캔버스(canvas)를 모두 비운다.
- 캔버스 두 번 해제: `makeCanvas` 가 실패하면 `canvas` 에 새 값이 들어가지 않아 `src === canvas` 인 채로 finally 에서 두 번 비운다. `freeCanvas` 는 `width = 0; height = 0` 만 하므로 두 번 불러도 탈이 없다. 성공 길에서는 `freeCanvas(src); src = null` 뒤라 한 번만 비운다.
- 썸네일: `w, h` 를 안전망 뒤에 읽으므로 썸네일과 `out.pages[].w/h` 가 줄인 캔버스 기준이다. 서버 commit 값과 WebP 머리 크기가 같다.
- pptx.js: 세로 슬라이드는 `cw = floor(2000 / ratio)` 이므로 `cw × ratio ≤ 2000` 이고, 렌더러의 높이 `round(slideHeight × cw / slideWidth)` 도 2000 을 넘지 않는다. `ch` 의 `Math.min(w, ...)` 는 렌더러가 캔버스 크기를 다시 정하므로 실제 결과에는 영향이 없다(안전한 덧붙임).
- 예외 전파: 안전망에서 나오는 일반 오류(메모리 부족 등)는 ConvertError 가 아니지만 `convert/index.js:62-67` 이 UNKNOWN 으로 감싼다. 썸네일 쪽에도 이전부터 같은 길이 있었으므로 새 길이 아니다.

## 2. 문제

치명과 높음은 없다. 고친 코드가 새로 만든 결함도 찾지 못했다.

### L1 [낮음] 고친 내용을 지키는 시험이 아직 없다(첫 감사 B-4 그대로)
- 파일:줄: `tests/zzoom/convert.test.mjs:108-135`. emitPage 시험은 2000×1400 이하만 넣고, 2001 이상은 `fitCanvas` 만 시험한다(126줄).
- 재현: `grep -n "dpr" tests/zzoom/convert.test.mjs` 결과 없음. pptx.js 의 `dpr: 1` 이나 core.js 안전망을 지워도 152개가 그대로 통과한다.
- 고칠 방향: (a) emitPage 에 3000×1688, 2001×1 캔버스를 넣고 `out.pages[0]` 의 w·h 가 2000 이하인지, 원래 캔버스가 0×0 인지 확인. (b) 안전망에서 drawImage 가 던질 때 두 캔버스가 모두 0×0 인지 확인(위 ④ 와 같은 방식). (c) pptx.js 소스에 `dpr: 1` 이 있는지 보는 정적 시험.

### L2 [낮음] 내림 때문에 세로 슬라이드의 긴 변이 2000 에 조금 못 미친다
- 파일:줄: `public/zzoom/convert/pptx.js:76-77`
- 재현: `audit2.py` 의 r1016.pptx 는 1968×1999(긴 변 1999), tall56.pptx 는 35×1960(긴 변 1960, 고치기 전에는 36×2016 을 그린 뒤 안전망이 36×2000 으로 줄였다).
- 영향: 서버 한도 안이라 거절은 없다. 해상도 손실은 1999 쪽이 0.05%, 극단 비율(1:56)이 2% 로 맨눈으로는 차이가 없다. 극단 비율 슬라이드는 실제로 거의 없다.
- 고칠 방향: 고치지 않아도 된다. 꼭 2000 을 채우려면 `cw = floor(2000 / ratio)` 로 그린 뒤 렌더러 높이가 1999 이하일 때만 `cw + 1` 을 시험해 2000 이하이면 그 값을 쓰는 방식이 있으나, 얻는 것이 적어 권하지 않는다.

### 참고(문제 아님)
- 첫 감사 M1(dpr:1 일 때 고해상도 그림 축소 품질)은 알려진 한계로 두기로 했으므로 다시 재지 않았다. 이번 고침으로 달라진 점은 없다.
- `core.js:232-238` 안전망과 `core.js:183 fitCanvas` 는 같은 계산이다. 나중에 정리할 때 try 안에서 `src = canvas; canvas = fitCanvas(src); if (canvas !== src) src = null;` 처럼 합칠 수 있다(다만 fitCanvas 가 중간에 실패하면 새 캔버스를 비우지 못하므로 그대로 둬도 된다).
