## 정한 것
- 쪽 지우기는 CONTRACTS 8절대로 3팀(draw.js), 화이트보드 띄우기는 3팀(board.js, `#zz-hostbar-board`). DESIGN_TEAMS 의 D5 줄과 다르지만 CONTRACTS 를 따랐다.
- 녹음 조각 번호 n 은 받은 기록의 가장 큰 n 과 이 탭이 쓴 번호(sessionStorage)보다 크게 잡는다(서버가 같은 n 을 덮어쓰므로).
- 녹음 고지 확인은 탭마다, 회의마다 한 번(sessionStorage).
- 「모두 내 화면으로」는 2팀에 `cmd:force` 만 보낸다. 실패 안내는 2팀 몫.
- 안건 지우기는 겹 모달을 피하려고 같은 단추를 4초 안에 한 번 더 누르게 했다(「정말 지우기」).
- 업로드는 한 번에 파일 하나.

## 요청
- 3팀(board.js): 600px 미만에서 「화이트보드 띄우기」를 그림 단추(44px, aria-label)로 줄여 주면 390px 에서 녹음 단추가 화면 안에 들어온다. 5팀 단추는 이미 최소다.
- 통합(zzoom.css): `#zz-hostbar` 는 높이 64px 한 줄 고정이다. 다른 팀 단추가 더 늘면 넘칠 수 있으니 막대에 `overflow-x:auto` 를 주면 안전하다.
- 서버(S): 회의를 끝내면(`ended`) `transcribe` 가 409 라 마지막 1분 조각이 버려진다. 끝낸 뒤 1~2분은 받아 주거나, 끝내기 전에 조각을 먼저 보내게 할지 정해 주면 맞추겠다. 지금은 실패 표시만 남는다.
- 서버(S)와 통합: 두 주관자가 각각 녹음을 시작하면 둘 다 녹음해 n 이 겹칠 수 있다. 누가 녹음 중인지(`recordingCid`)를 회의 문서에 두면 「다른 기기에서 녹음 중」을 정확히 보이고 막을 수 있다.
- 감사 08(PNG 대체 출력): 지금 `uploadAgenda` 가 WebP 가 아니면 `webp_unsupported` 를 던지고, 화면은 「엣지나 크롬 최신판에서 올려 주세요」로 보인다. api 가 PNG 를 받게 바뀌면 화면은 고칠 것이 없다.
- 시험 가짜 api 에 `acceptLive` 를 넣었다(app.js 가 새로 부름). api.js 에 함수가 더 생기면 `tests/zzoom/d5_fake_api.js` 에도 넣어야 한다.

## 남은 일
- 실제 서버와 Firebase, 실기(태블릿 녹음 1분)는 못 돌렸다. 가짜 api 로만 시험했다.
- 390px 진짜 조립의 녹음 단추 잘림은 3팀 요청이 들어가면 다시 확인.

## 화면 감사 R1 반영 (AUDIT_UI_R1.md 중 5팀 몫)
| 지적 | 고친 곳 | 어떻게 |
|---|---|---|
| U09 녹음 중 나가면 마지막 조각과 대기열 유실, 녹음 멈춤 안 알림 | `record.js` `flushNow()`, `ChunkQueue.takeAll()`, `mount` 의 `pagehide` | 녹음기를 `start(1000)` 으로 돌려 1초마다 데이터를 받아 둔다. 나갈 때(unmount: 로고·목록 이동) 와 탭 닫기(`pagehide`) 에 기다리지 않고 바로 ① 지금 조각을 받아 둔 데이터로 끊어 ② 남은 대기열(재시도 대기·실패 포함, 보내는 중 제외)과 함께 `api.transcribe` 를 시작하고 ③ 이 탭이 녹음하던 중이면 `setState('recording', false)` 를 보낸다. 요청이 unmount 안에서 시작되므로 app 이 곧바로 `api.leave` 로 자격을 지워도 이미 나간 요청은 간다. 모든 조각에 시작 시각 `at` 을 싣는다(서버의 「끝난 뒤 2분, at 이 끝 시각 이전」 규칙에 맞음). 창 닫기 경고(`beforeunload`)는 녹음 중이거나 대기열이 남았을 때 계속 뜬다 |
| U10 화면 문구 가운뎃점 `· 지금 보는 안건` | `host.js` 안건 관리 줄, `host.css` | 「지금 보는 안건」 칩으로 바꿈 |
| U11 (api 문구) 중 업로드 실패에 파일 이름 노출 | `upload.js` `errorText` | `upload_failed` 는 「쪽 그림을 올리지 못했어요. 연결을 확인한 뒤 「다시 올리기」를 눌러 주세요.」로 바꿔 보임(api.js 는 고치지 않음) |
| U12 바이트코드 캐시의 계정 폴더 이름 | `tests/zzoom/__pycache__/` | 지웠다(디버그 때 d5_e2e 를 import 해서 생긴 것) |

탭 닫기의 한계: 브라우저는 페이지를 닫을 때 진행 중인 일반 fetch 를 끊을 수 있고, `keepalive`·`sendBeacon` 은 64KB 까지라 1분 조각(약 240KB)은 못 싣는다. 그래서 탭 닫기는 최선 노력이다(닫기 전 경고 창이 먼저 뜬다). 요청: ① api.js `setState`·`transcribe` 에 `keepalive` 선택지(멈춤 알림은 작아서 확실히 감) ② 서버가 녹음하던 주관자의 `heartbeat {leaving:true}` 를 받으면 `recording:false` 로 바꾸기(가장 확실).
