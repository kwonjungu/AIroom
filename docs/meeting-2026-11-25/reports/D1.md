# D1 보고 (목록·입장·브랜드)

## 만든 파일
- `public/zzoom/list.js` : 회의 목록. 관리자만 만들기·수정·삭제·잠금 풀기 단추. 진행 중 회의를 맨 위로, 상태 칩, 일시(한국 시간), 안건 수, 「n일 뒤 삭제돼요」(2일 이하는 귤색 강조), 빈 화면 그림(`empty-list`), 연결 오류 시 「다시 불러오기」, 탭이 다시 보이면 새로 고침.
- `public/zzoom/join.js` : 입장 덮개(이름 칩 + 직접 입력, `rememberedName` 기본값, `hero-join`, 입장 뒤 `rememberName`), 머리줄 「내 이름」 + 「주관 코드 넣기」(6자리 모달, 남은 횟수·429·423 안내), 주관자면 「주관자」 칩, 410 삭제된 회의 안내.
- `public/zzoom/list.css` : `.zl-` 접두사, `--zz-*` 변수만, 44px 터치, 768px 미만 대응. 두 모듈이 같은 css 를 export.
- 시험: `tests/zzoom/d1.unit.test.mjs`, `d1_e2e.py`, `d1_harness.js` (모두 새 파일).
- 로고는 `assets/logo.webp`(뼈대 index.html 머리줄이 이미 씀)와 목록 머리에 56px 로 씀. 에셋은 기존 것 그대로(새로 만들지 않음).

## 정한 것
- join.js 는 `#zz-join` 의 보임·숨김을 만지지 않는다(app.js 가 정함). 안쪽만 그린다.
- 실제 `api.session(mid)` 는 입장 뒤에만 값이 있어서, 이어 들어가는 중 깜박임을 막는 분기는 넣지 않음(app 이 resume 실패 때만 덮개를 보임).
- 모달 단추는 `ctx.modal` 의 actions 대신 본문 안에 둠(실패 때 창을 안 닫기 위해). 창 닫기·Esc 는 app 의 모달이 처리.
- 주관 코드 칸은 maxlength 대신 스크립트로 숫자 6자리만 남김(붙여넣기 대응).
- 시험은 가짜 api/store 만 사용, Firebase·Redis 쓰기 없음. 커밋·푸시 안 함.
