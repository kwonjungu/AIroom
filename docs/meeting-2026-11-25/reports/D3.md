## 추가 지시 반영
1. **1초 묶음 전송**(LOAD.md): 손 떼면 대기열에 넣고, 1초에 한 번 `{strokes:[최대 20]}` 로 보냄. 429·연결 끊김·5xx 는 지수 백오프(1·2·4·8·16초)로 다시 보내고 그동안 화면에는 그대로 보임. 6번 실패한 선만 흐리게(0.3) + 「선 n개를 보내지 못했어요 / 다시 보내기」. `conn.server` 가 `ok` 로 돌아오면 한 번 자동 재시도. 400·`stroke_limit`·`state_*`·410·403 은 다시 보내지 않고 안내. 409 `stale_epoch` 는 그 쪽 옛 선만 버리고 나머지는 다시 보냄. 획마다 시작할 때 pageKey·epoch 를 고정하므로 쪽을 넘겨도 원래 쪽으로 저장.
2. **구독**: `api.subscribePageStrokes(pageKey, cb)`(선 배열, 현재 epoch, seq 순)만 씀. api.js 에 아직 없어서 draw.js 안 `pageStrokesSource()` 어댑터가 옛 `subscribeStrokes`+`subscribePageEpoch` 로 같은 모양을 만든다(있으면 그것을 그대로 부르고, 인자 3개 `(mid, pageKey, cb)` 모양도 받음). 최근 3쪽 LRU 는 api.js 몫이라 draw.js 는 지금 쪽 하나만 구독(`PAGE_LRU = 1`). epoch 는 새 선에 붙일 값과 옛 대기 선 정리에만 쓰려고 `subscribePageEpoch` 를 따로 듣는다. 그릴 때 epoch 로 다시 거르지 않는다(묶음 문서의 선에는 epoch 가 없을 수 있어서).

1. **통합(api.js)**: `subscribePageStrokes(pageKey, cb)` 를 넣으면 draw.js 어댑터는 자동으로 그것을 쓴다. 넣은 뒤 draw.js 의 `pageStrokesSource` 옛 경로는 지워도 됨(알려 주면 3팀이 정리). cb 둘째 인자로 `{epoch}` 를 주면 `subscribePageEpoch` 구독도 뺄 수 있다(읽기 1개 줄임).
2. **통합(zzoom.css)**: 820px(갤럭시탭 세로) 폭에서 안건 240px + 옆칸 340px 고정이라 무대가 240px 밖에 안 된다. 1024px 미만에서는 안건 목록을 덮개로 돌리는 등 무대를 넓혀 주기 바람. 그동안 도구 막대는 가로로 밀어 보도록 해 둠.
3. **통합(zzoom.css, 선택)**: 형광펜 multiply 는 ink canvas 안에서만 섞인다(바탕 그림과는 겹침만). 문서 글자 위에서 더 진짜 형광펜처럼 보이게 하려면 `#zz-layer-ink { mix-blend-mode: multiply }` 를 고려(펜 색은 흰 바탕에서 그대로라 영향 적음).
4. **2팀(viewer.js)**: 지금 코드처럼 `#zz-pagebar` 안 `#zz-board-actions` 를 지우지 않는 것을 유지해 주기 바람. 펜 모드에서 진행자 따라가기로 쪽이 넘어가도 그리던 획은 원래 쪽에 저장된다(정상).
5. **서버(S)**: 판서 1초 1회 고정 창이라 첫 묶음 직후 손을 떼면 최대 1초 늦게 저장된다. 토큰 통(초당 1, 순간 3)으로 바꾸면 더 빨라진다(LOAD.md 2번과 같은 뜻).
