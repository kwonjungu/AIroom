# 사용자 결정 사항 (2026-11-25, 설계서 반영 대기)

DESIGN.md 감사 중에 사용자가 정한 것. 감사 결과와 함께 DESIGN.md 에 반영한다.

1. **보안**: Firebase 맞춤 토큰 방식(서비스 계정 키). 
2. **열쇠 10일**: 회의 열쇠는 그 회의에서 처음 발급한 시각부터 10일 유효. 서버는 10일 뒤 발급 거절, 규칙은 토큰 claim `until`(ms)을 `request.time` 과 비교해 막는다.
3. **기록도 10일 뒤 삭제**: 첫 발급 시각(발급이 없으면 만든 시각) + 10일이 지나면 Storage(그림·원본)·Firestore(상태·접속자·그림·투표·채팅·대화 기록)·Redis(회의·주관 코드 해시) 모두 삭제. 30일 보관안 폐기. 목록에 「D-n 뒤 삭제」, 관리자 즉시 삭제, 안건마다 「원본 받기」.
4. **채팅**: `meetings/{id}/chat/{msgId}` `{cid,name,text≤500,at}`. 열쇠 가진 사람만 읽기·쓰기, 글쓴이 cid 일치, 지우기는 본인·주관자, 끝난 회의는 쓰기 잠금. 오른쪽 접이식 칸, 안 읽은 수, 「지금 쪽 붙이기」(누르면 그 쪽으로 이동), 기기당 1초 1글, 최근 200개.
5. **화이트보드**: 주관자 「화이트보드 띄우기」 → 안건 목록에 `화이트보드 n`(kind 'board', 그림 파일 없음, 바탕 흰색·모눈·줄). 쪽 추가 가능. 선은 같은 strokes, 쪽 키 `board:<n>:<p>`.
6. **펜 모드에서만 판서**: 기본 보기 모드(한 손가락 끌기=이동, 두 손가락=확대). ✏️ 펜 모드를 켜야 형광펜·펜·지우개(안건·화이트보드 공통). 펜 모드에서도 두 손가락은 이동·확대. 기기별, 쪽 넘겨도 유지. 판서 권한: 기본 모두, 주관자가 「판서 잠금」 켜면 주관자만(사용자 별도 지시 없어 제안안 채택).
7. **녹음 → 대화 기록**: 주관자 기기만 ⏺ 녹음(MediaRecorder). 모두에게 「● 녹음 중」 표시, 처음 시작 때 고지 확인. 1분 단위 조각을 서버로(Vercel 4.5MB 한도) → Groq Whisper(`whisper-large-v3`) → `meetings/{id}/transcript/{n}` `{at, text, agendaId, page}`. 소리 파일은 저장하지 않음. 화자 구분 없음. 학생 개인정보 말하지 말라는 안내.
9. **이름: 쭘 (ZZOOM)**. 화면 제목·탭 제목·메인 바로가기 카드 모두 「쭘」. 주소는 `/zzoom`(설계서의 `/meeting`·`public/meeting/`·`lib/meeting/`·`/api/meetings` 는 `zzoom` 으로 바꾼다. Firestore 컬렉션은 `zzoom_meetings`). 로고·색은 우리 것으로 만들고 Zoom 의 파란 카메라 로고·색은 흉내 내지 않는다.
10. **에셋은 SVG 금지, 코덱스로 직접 생성**: 로고·도구 아이콘(펜·형광펜·지우개·손·투표·녹음·채팅·화이트보드 등)·빈 화면 그림·입장 화면 그림은 코덱스 이미지 생성으로 PNG(투명 배경)를 만들고 WebP로 줄여 `public/zzoom/assets/` 에 둔다. 손으로 쓴 SVG·아이콘 폰트·이모지 대체 금지. 에셋 목록·크기·생성 프롬프트는 `docs/meeting-2026-11-25/ASSETS.md` 에 남긴다(다시 만들 수 있게). 원본 PNG 는 gitignore 폴더, 저장소에는 줄인 WebP만.
8. **AI용 md 내보내기**: 주관자·관리자 「📄 AI용 기록 받기」 → `회의제목_날짜.md`(회의 정보·안건·대화 기록(시간·안건·쪽 표시)·채팅·투표 결과·AI 부탁 예시). 서버에 저장하지 않고 누를 때마다 생성.
